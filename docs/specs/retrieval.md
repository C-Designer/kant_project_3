## 범위

- 책임: 질의를 받아 벡터스토어에서 관련 청크를 찾아 돌려준다. 하이브리드 검색·리랭킹을 넣는다면 여기다.
- 책임 아님: 적재(`ingestion`), 찾은 청크를 프롬프트에 어떻게 넣을지(`agent`).

## 동작

미정. 벡터스토어가 정해진 뒤 작성한다.

코드 위치: `src/retrieval/`

## 인터페이스

- 입력: 질의 문자열, 반환 개수, 메타데이터 필터(선택)
- 출력: 청크 목록. 각 항목은 `text`, `score`, `metadata`. `ingestion`의 레코드 형식을 그대로 쓴다.
- 모든 검색 호출은 `observability`로 트레이스한다.
