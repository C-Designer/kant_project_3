## 범위

- 책임: 튜터가 전달할 데이터셋을 읽어 청킹·임베딩한 뒤 벡터스토어에 적재한다. 재적재(전체·증분)도 여기서 한다.
- 책임 아님: 질의 시점의 검색(`retrieval`), 임베딩 모델 외의 LLM 호출.

## 동작

미정. 데이터셋 수령 후 결정한다.

- 청킹 전략(크기, 겹침, 구조 기반 분할 여부)
- 임베딩 모델
- 벡터스토어 선택과 스키마

코드 위치: `src/ingestion/`

## 인터페이스

- 입력: 원본 데이터셋 파일 (형식 미정)
- 출력: 벡터스토어 레코드. 최소 필드는 `id`, `text`(청크 원문), `embedding`, `metadata`(출처 문서, 위치). `retrieval`이 이 형식에 의존한다.
