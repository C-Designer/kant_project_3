## 범위

- 책임: Langfuse로 LLM 호출·검색 호출을 트레이스하고, 평가 데이터셋과 점수를 관리한다.
- 책임 아님: 애플리케이션 로직. 다른 영역이 이 영역의 함수를 호출해 트레이스를 남긴다.

## 동작

미정. Langfuse 운영 방식(Cloud / 셀프호스트)은 추후 결정한다.

핵심 규칙(확정):
- 트레이스에 남는 프롬프트·응답은 `masking`을 거친 것이어야 한다.
- API 키 등 설정은 환경 변수로만 넣는다. 저장소에 커밋하지 않는다.

코드 위치: `src/observability/`

## 인터페이스

- 트레이스 시작/종료, 스팬 기록, 점수 기록 함수. 구체 시그니처는 스택 결정 후 작성한다.
- 환경 변수: `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, `LANGFUSE_HOST`
