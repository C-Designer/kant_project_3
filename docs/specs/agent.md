## 범위

- 책임: 사용자 요청을 받아 컨텍스트를 조립하고(컨텍스트 엔지니어링: 검색 결과 선택·압축, 시스템 프롬프트, 대화 이력 관리), 도구 호출 루프를 돌리고, 최종 응답을 만든다.
- 책임 아님: 검색 자체(`retrieval`), 마스킹(`masking`), 트레이싱(`observability`).

## 동작

미정. 언어·프레임워크 ADR 이후 작성한다.

핵심 규칙(확정):
- LLM API 호출은 반드시 `masking`을 거친 메시지로 한다. 우회 경로를 두지 않는다.
- 모든 LLM 호출은 `observability`로 트레이스한다.

코드 위치: `src/agent/`

## 인터페이스

- 입력: 사용자 메시지, 세션 식별자
- 출력: 응답 텍스트와 사용한 출처(청크 `metadata`)
- 의존: `retrieval`(청크 목록), `masking`(메시지 마스킹·복원), `observability`(트레이스)
