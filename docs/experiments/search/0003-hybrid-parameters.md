## 해석·한계

- 결과가 말해주는 것: Advanced에서 방식 차이가 크다(naive Recall 0.422, hybrid 0.589, hybrid_rerank 0.635). Basic은 방식 사이가 구별되지 않는다(원본 4절). 파라미터는 Basic·Intermediate에서 현재값이 최고이거나 구별 불가다. Advanced hybrid만 볼 때는 E5 무게 w <= 0.4와 작은 POOL이 높았으나(E5가 거의 기여하지 않고 BM25가 일함), hybrid_rerank에서는 그 이득이 사라졌고 어느 조합도 baseline을 뚜렷하게 이기지 못했다(차이 -.035 ~ +.018). 번호 통째 조각은 두 질문 집합 모두 baseline 이상이며 개발용 후보 단계 모든그룹 .552 -> .690은 후보 확대·무게·2+3으로 못 움직이던 한계를 처음 움직였다. additional의 이득은 작다(rerank Recall +.009, 인용문 모든그룹 +1문항).
- 말해주지 못하는 것: 28~29문항이라 .02 안팎과 ±.04는 노이즈다. 5.19절 3-gram·2+3은 k=10 Recall이 +.12 좋지만 k=5는 개발용에서만 오른다(+.032·+.052, additional +.003·+.005)라 k=5 기준으로 일관되지 않다. POOL 3·5·7은 Advanced에서 재지 않았다. Advanced에서 번호 통째가 Basic·Intermediate에서 손해가 없는지는 미확인이다(BM25 설정은 모든 난이도가 공유). 원본 5.47절은 Intermediate에서 번호 규칙을 "손해였음"으로 적었으나 그 측정은 이 문서 범위 밖이다.
- 조건이 달랐던 점이 결과에 준 영향: POOL 10은 두 검색기 후보가 겹치면 rerank 후보 20개를 못 채울 수 있어 rerank에서는 POOL 20 이상이어야 한다(5.18·5.20절).
- 방식 간 차이가 실험 효과인지 우연인지 확인한 방법: 두 질문 집합에서 방향이 함께 가는지, 같은 실행에서 baseline을 다시 재서 5.22절 값과 일치하는지 확인했다(5.23절). 5.43절은 두 집합 모두 기준을 +.03 넘게 이긴 설정이 없고 최대 이득 POOL 30(rerank) 개발용 +.021이 additional에서 -.041이라고 적었다.

## 결정·후속 작업

- 결정(원본 기록의 판단, 잠정): hybrid 현재값(POOL 20, RRF 60, 무게 1:1, 2-gram, k1 1.5·b 0.75) 유지. 합치는 방식은 RRF 유지(z-score는 28문항 크기의 차이, 점수 범위에 의존하지 않는 점도 이유). Advanced의 POOL 10·w 0.3~0.4는 Advanced에서만 나았고 rerank에서는 이득이 사라져 채택하지 않음. 2+3 혼합은 2-gram 유지(Advanced를 최종 난이도로 정하면 재검토). 번호 통째는 "2-gram + 번호 통째가 후보"로 기록되었고 저장소 반영 여부는 원본에 결정이 없다.
- 갱신한 것: 없음(원본은 "저장소는 바꾸지 않았다"를 반복 기록).
- 다음 실험 또는 Issue: 번호 통째의 Basic·Intermediate 손해 확인(원본 5.28절 미확인 항목), hybrid_rerank에서 확정 청킹 hybrid 파라미터 재측정(원본 5.10절 미측정).
