# 실험 A. 검색 방식 4종과 새 방식의 후보 수 (E1–E5)

## 요약

- 답변 품질은 네 방식이 비슷하다(Faithfulness 0.92–0.96, 사실 0.72–0.76).
- 차이는 비용이다. 새 방식(subq)은 응답이 약 2–2.5배 느리고 출력 토큰이 약 1.5배다.
- 새 방식의 후보 수 50 → 20은 Recall·품질을 유지하고 응답을 22% 줄여 **채택**했다(#128).

## 결과 (모든 실험에서 Hit@5 = 1.00, 오류 0건. *는 해석 보류)

E3 (4방식, 같은 25문항, 후보 50):

|---|---|---|---|---|---|---|
| naive | 0.85 | 0.88 | 4.8 | 0.92 | 0.72 | 0.92 / 1.00 / 0.96 |
| hybrid | 0.84 | 0.83 | 4.8 | 0.96 | 0.72 | 1.00 / 1.00 / 0.88 |

E4 (새 방식 후보 20): Recall 0.84, MRR 0.91, 응답 중앙값 **12.1초**(−22%), Faithfulness 0.96, 사실 0.80. 기존 3방식은 E3과 검색이 같아 미채점.

E5 (근거 6·7개 질문 교체): Recall naive 0.80, hybrid 0.80, hybrid_rerank 0.81, 새 방식 0.84(유지). 채점 전.

E1 / E2 (3방식 비교용): E1 Recall 0.67 / 0.74 / 0.70, E2 0.85 / 0.84 / 0.87 (naive / hybrid / hybrid_rerank). 15문항과 25문항의 Recall 절대값은 비교하지 않는다(근거 7개 질문 2개가 15문항에만 있음).

## 해석·결정

- 답변 품질은 방식 사이에 차이가 없고(Faithfulness 0.92–0.96, 사실 0.72–0.76), **차이는 비용**이다(새 방식 응답 약 2–2.5배, 출력 토큰 약 1.5배).
- 후보 50 → 20: Recall 같고(0.85 대 0.84), 품질 하락 신호 없음, 응답 22% 감소 → **채택**(`main` 값 20, PR #128).
- 조건·근거·판단은 채점이 흔들려 해석 보류. 사람 대조에서 S-FINAL-29, S-DEV-27이 사람 1점·AI 0점으로 갈려 팀 해석이 필요하다.
