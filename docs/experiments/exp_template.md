## 비교 조건

바꾼 변수는 **하나만**. 나머지는 [evaluation.md "비교 조건"](../evaluation.md)대로 동결하고 세 방식(또는 비교 대상)에 같게 적용한다.

| 구분 | 값 |
|---|---|
| 바꾼 것 (기준 → 실험) | 예: `hybrid_rerank` 후보 수 50 → 20 |
| 비교 대상 방식 | 예: naive / hybrid / hybrid_rerank / hybrid_rerank_subq |
| 동결 확인 (PDF·추출·청킹·임베딩·생성 모델·답변 프롬프트·생성 설정·`k`·토큰 한도·timeout·재시도) | `src/config.py` 값과 같음 / 다른 것: |
| 기록할 것 (결합 방식·가중치, 리랭커 모델·후보 수, 평가 모델·프롬프트·설정) | |
| 색인 | 로컬 모드(`QDRANT_URL` 비움) / 공용(색인 변경 없음) |
| 코드 상태 | `git_commit`: / `git_dirty`: (`run_meta.json` 값) |

조건이 달랐던 방식이 있으면 여기에 적고 [해석·한계](#해석한계)에 반영한다.
